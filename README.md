TASK 4 – ROCK PAPER SCISSORS GAME USING PYTHON
1. Introduction

The Rock Paper Scissors Game is a simple and interactive Python-based project developed as part of my CodeSoft Python Programming Internship.

Rock Paper Scissors is a popular hand game played between two players. In this project, the user plays against the computer. Both the user and the computer select one option from Rock, Paper, and Scissors. Based on the selected choices, the program determines the winner.

This project is designed to improve Python programming knowledge and understand the implementation of basic game logic.

3. Project Description

The Rock Paper Scissors game is developed using Python programming language.

In this game, the user selects one of the three options: Rock, Paper, or Scissors. The computer automatically selects a random option using Python's random module.

The program compares both choices and determines the result according to the game rules.

The game continues based on the program's implementation and displays whether the user wins, loses, or gets a tie.

4. Rules of the Game

The game follows three basic rules:

Rock beats Scissors.
Scissors beats Paper.
Paper beats Rock.

If both the user and computer select the same option, the result is a Tie.
